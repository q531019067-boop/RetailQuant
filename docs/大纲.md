## 项目定位

**RetailQuant 是面向 A 股个人投资者的本地量化系统**——单实例运行、本地优先存储、无需外部券商或云账号。

和普通看盘软件的区别：**策略引擎是 rQuant 主包的核心**，Web 看板只负责展示与操作，不承载策略逻辑。

仓库内另有 **rbacktest 子系统**——基于 VNPY Alpha 的独立 Web 回测应用，与 rQuant **零代码依赖**，策略与数据格式各自隔离。

### 解决什么问题

| 痛点 | 本项目做法 |
|------|-----------|
| 只会看行情、缺少系统化买卖依据 | 12 个注册策略输出统一 `Signal`（买入/卖出/信心度/止损止盈） |
| 策略想法难以在历史数据上验证 | CLI 研究链路：板块选池 → 拉数 → 多策略评分 → 组合模拟 → 收益矩阵 |
| 多数据源不稳定 | `DataSourcePool` 健康度路由 + SQLite/Parquet 本地缓存 |
| 持仓与资金分散记录 | `portfolio` + `funds` 双存储，Web 表单统一更新 |
| 策略横向对比需要专用 UI | rbacktest 独立 React 回测页，7 策略并行对比 + LLM Agent 辅助分析 |
| 收盘后缺少系统化复盘 | `rquant/review/` 自动扫描 → 报告 → 可选邮件 / GitHub Release |

### 多轨能力总览

```
┌──────────────────────────────────────────────────────────────────────────┐
│  rQuant 主系统（共享 rquant/strategy/ 策略核心）                           │
├────────────────────────────┬─────────────────────────────────────────────┤
│  实盘看板轨（日常）         │  研究回测轨（验证）                           │
│  python app.py → :8080    │  scripts/*_pool.py 等 + backtest engine     │
│  持仓 / 自选 / 板块 / 信号  │  选池 / 评分 / 模拟 / 矩阵对比               │
│  rquant/web/ + business/  │  rquant/research/ + backtest/               │
├────────────────────────────┼─────────────────────────────────────────────┤
│  日复盘轨                   │  蒙特卡洛扩展（嵌入看板）                      │
│  scripts/review.py         │  GET /api/montecarlo/<code>                 │
│  + 可选 scheduler / Actions │  rquant/research/montecarlo/                │
└────────────────────────────┴─────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────┐
│  rbacktest 子系统（独立，不 import rquant）                                │
│  rbacktest/start.sh → Flask :15000 + React :5173                         │
│  VNPY Alpha 回测 + 7 策略对比 + LLM Agent                                 │
└──────────────────────────────────────────────────────────────────────────┘
```

- **实盘看板轨**：Flask 单页看板，板块 Treemap、自选股分析、持仓与资金管理。
- **研究回测轨**：命令行批量跑历史窗口，验证策略在候选池上的可复现表现。四步链路：`select_board_pool` → `fetch_hist_for_pool` → `score_stock` → `simulate_trading`。
- **日复盘轨**：扫描 enabled 标的池 → 12 策略 → Top-5 信号 → 图表 → Typst/PDF/HTML 报告。
- **蒙特卡洛扩展**：个股路径 stress test，嵌入看板自选股/持仓行。
- **rbacktest 对比轨**：VNPY Alpha 驱动的策略横向排名验证，含 LLM Agent 对话分析。
- **场景样例轨**（`examples/`）：薄编排组合 `scripts/` 层命令；产物与样例同目录存放。

### 设计原则

1. **本地优先**：K 线、财务快照、持仓默认落本地 SQLite / Parquet / JSON。
2. **策略与展示分离**：新策略只改 `rquant/strategy/`，Web 层调用 `scan_stock()` 等 API。
3. **防未来函数**：研究链路所有决策使用 `date <= as_of` 的 K 线切片。
4. **显式联网**：评分/模拟默认不隐式拉数；需要时用 `--fetch-missing` 或单独跑数据准备脚本。
5. **子系统隔离**：rbacktest 与 rQuant 策略注册、Parquet 格式、Web 端口完全独立，不可混用数据目录。

### ★ `rquant/strategy/` — 策略核心

新增策略时改策略包，不把策略逻辑写进 Web 层。注册方式：`@register` 装饰器，子模块导入触发注册。

|------|----------|
| `BuyHold` | legacy |
| `ChanLun2B` | legacy |
| `MovingAverageCross` | trend |
| `RsiMeanReversion` | mean_reversion |
| `GridMartingale` | grid |
| `DonchianTurtle` | turtle |
| `VpBreakout` | volume_breakout |
| `CrossBorderDca` | etf_rotation |
| `DividendLowvolRotation` | etf_rotation |
| `DragonTigerPattern` | pattern |
| `MultiFactor` | factor |
| `ScenarioRouter` | router |

统一入口：`from rquant.strategy import scan_stock, scan_sell, scan_category, get, all_strategies`

## 陷阱

1. **策略逻辑只在 `rquant/strategy/`**；根目录 `app.py` 仅启动 Web，不存在根目录 `strategy.py`。
2. **rQuant 与 rbacktest 数据不可混用**——Parquet 路径、代码格式、策略注册机制均不同。
3. **Sina / 东方财富接口都会挂**，下游要容错空返回或 stale 缓存。
4. **自选股已迁移到 SQLite meta**，`data/watchlist.json` 只做老数据迁移。
5. **资金和持仓存储不完全一致**——`funds.py` 支持多用户目录，`portfolio.py` 仍为全局单文件；买卖路由需同时更新两者。
6. **复盘默认关闭**——`config.review.enabled=false`，scheduler 不执行分析。
7. **rbacktest Agent 需 `DEEPSEEK_API_KEY`** 环境变量，见 `rbacktest/rbacktest.toml [agent]`。
